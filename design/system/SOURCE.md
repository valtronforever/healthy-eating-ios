# Source of this spec

These files are copies of the approved Healthy Eating design system, published as a Claude
Design System artifact (https://claude.ai/artifact/8JTaMfHzKZLSWYj5VhYk2r, version
`1792321896-e79d`, copied 2026-10-18):

- `README.md`: brand book (principles, color, type, space, components, screens, charts,
  iconography, accessibility, dark mode).
- `tokens.json`: color (light and dark), type, spacing, radius and shadow tokens.
  `design/tools/generate_design_tokens.py` turns it into the app's color sets and Swift tokens.
- `content.md`: copy rules.
- `app-icon.md`: app icon usage; the icon files themselves are in `design/icon/`.
- `components/<Name>/README.md`: one guideline per component.

The high-fidelity screen boards (A1 to G3) and wireframes are only in the artifact. When the
artifact changes, copy the changed files here and rerun the token generator.
