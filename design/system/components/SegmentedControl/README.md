# SegmentedControl

The system segmented picker. Used for the Trends period (7 / 30 / 90 days) and the assistant switch in Connect your AI assistant.

- Props: `options` (2 to 4 short labels), `value`, `onChange`, `label` (accessibility name).
- SwiftUI: `Picker(...).pickerStyle(.segmented)`. Do not restyle it beyond the system look.
